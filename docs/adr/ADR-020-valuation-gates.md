# ADR-020 Valuation gates

- Status: accepted
- Date: 2026-11-03

## Context

A company valuation was discussed as a vision. No revenue, customer count, or multiple in the program plan was verified. The figure is an **ASSUMPTION**, a vision, not a plan result and not a forecast.

## Decision

No pitch, UI string, or agent may state that figure as expected, likely, or supported by revenue. A founder may discuss it with investors only after all of the following are true, each still an **ASSUMPTION** about what would make the discussion honest:

- at least one customer dossier cites the coverage map in the customer's own words
- a double-digit count of aircraft programs is on a renewal, not a pilot
- a customer's design-assurance manual references the tool pack as an aid
- services hours per new customer are under a cap the founders set before the first pilot
- the employment-IP gate is still clean

Missing any one, the company is still the evidence product and the valuation talk stays off. These gates do not promise that meeting them produces any particular valuation.

The demo page must not contain that figure. `docs/legal/gate.md` records a founder-directed start. It is not a record that counsel was consulted.

## Alternatives

Printing the vision number in the product UI was rejected.

## Consequences

The product ships the ledger, the four agents, and the abstain path. It does not ship a valuation claim.
