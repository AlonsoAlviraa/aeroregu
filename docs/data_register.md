## Rules for a new row

1. Open the licence or the copyright notice. Paste the URL and the date. Do not paste a long copyrighted text.
2. Set the label to VERIFIED only for the fact that was read. A VERIFIED download page does not make the licence VERIFIED.
3. Record the SHA-256 of any file kept outside git. Do not commit the file if the notice forbids it.
4. Refuse a row whose source is an employer, a customer who has not contracted for reuse, or a document marked export-controlled.
5. Synthetic rows name the generator version and the seed.
