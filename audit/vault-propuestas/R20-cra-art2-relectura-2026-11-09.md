# Propuesta — no copiada al vault

Leído el 9 nov 2026. El artículo 2.1 aplica a productos con elementos digitales comercializados cuya finalidad prevista o uso razonablemente previsible incluye una conexión de datos, lógica o física, directa o indirecta, con un dispositivo o una red.

El artículo 2.3 dice que el reglamento no se aplica a los productos con elementos digitales que hayan sido certificados conforme al Reglamento (UE) 2018/1139. La exclusión es del producto certificado, no de una herramienta de escritorio que no tiene certificado. El propio README dice que esta herramienta no está cualificada ni aceptada por la autoridad.

Si el producto se vende con conexión de datos y no está certificado bajo 2018/1139, el artículo 2.1 puede alcanzarlo. Si no hay conexión, el 2.1 no se cumple. Las dos frases son lectura del artículo, no una clasificación del producto. Eso lo cierra un abogado.
